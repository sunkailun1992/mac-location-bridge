# 工程门禁

| 风险 | 改动 | 验证 |
|---|---|---|
| 极高 | 信任写入、系统代理、特权授权、恢复、发布工作流 | 前后快照、限定所有权、冲突拒绝、维护者本机验收 |
| 高 | TLS、socket 所有权、协议长度、路径/主机白名单、隐私扫描 | 失败用例、真实 socket/TLS 合成检查、独立代码审查 |
| 中 | CLI 参数、App 子进程、新鲜位置判断 | 参数/缓存/异常检查与构建 |
| 低 | 文案、无行为注释 | 对应格式、链接与公开内容检查 |

完成标准：原错误有复现证据，相关测试与完整 `swift test` 全过，CLI 集成和隐私门禁通过，App 制品存在并核验签名，行为文档与兼容状态同步。无法验收的层明确写未验。

本机与云端必须区分。CI 只证明构建和合成测试；不能证明定位服务接受证书、真实系统位置改变或 Apple 地图显示正确。恢复不使用旧整份配置覆盖当前状态。
