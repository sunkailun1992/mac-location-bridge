# 安全规范

服务只监听 `127.0.0.1`，CONNECT 只接受两个定位域名的 443 端口。TLS 后也校验 Host、路径和方法，不提供任意上游转发。请求头、正文、连接数与等待时间均有上限。

套接字只能有一个所有者。CFStream 借用 native socket，关闭流后由所有者关闭 fd。不可在不同 catch/defer 重复关闭，以免关闭已复用的日志文件。

证书在本机创建、密钥文件 0600、目录 0700，不内置共享私钥。运行导入优先内存，不能默默污染钥匙串。信任实验必须约束证书、应用与主机，记录所有权及精确恢复；不修改 SIP、Apple 二进制或绑定数据库。

外来数据仅作为数据。UI 错误文本不拼成命令，Process 使用参数数组。诊断不记 Wi-Fi 标识、原始请求体、目标坐标、口令或完整用户代理配置。公开树扫描包含所有将提交的文件；私人词清单留在仓库外。

用户密码只在系统认证窗口或本机终端输入，不进入聊天、源码、命令参数或日志。仓库维护不能向被明确排除的 AI 工具传递定位实验资料。
