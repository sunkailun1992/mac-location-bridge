# AI 编码规范

本项目使用 Codex。根目录 `AGENTS.md` 是入口；规则冲突以用户当次授权和该文件为准。下列规范从既有个人开源项目的工程实践抽取，并按 Swift/macOS 的风险重新编写，不复制业务配置或内部资料。

| 文件 | 职责 |
|---|---|
| [AI_CODING_GUIDE.md](AI_CODING_GUIDE.md) | 分层、数据流、变更方式 |
| [AI_ENGINEERING_GUARDRAILS.md](AI_ENGINEERING_GUARDRAILS.md) | 风险与完成标准 |
| [SECURITY_CODING_SPEC.md](SECURITY_CODING_SPEC.md) | 证书、文件、网络与权限 |
| [TESTING_SPEC.md](TESTING_SPEC.md) | 合成测试、集成、实机 |
| [AI_DIRECTORY_STRUCTURE_GUIDE.md](AI_DIRECTORY_STRUCTURE_GUIDE.md) | 目录职责 |
| [AI_COMMENT_STYLE_GUIDE.md](AI_COMMENT_STYLE_GUIDE.md) | 语言与注释 |
| [AI_DESIGN_PATTERN_GUIDE.md](AI_DESIGN_PATTERN_GUIDE.md) | 接缝与所有权 |
| [VERSIONING_SPEC.md](VERSIONING_SPEC.md) | 版本与制品 |

可公开参考的实践来自 [IssueRelay](https://github.com/sunkailun1992/issuerelay/tree/main/docs/ai-coding)、[TradingView Capture](https://github.com/sunkailun1992/tradingview-capture-mcp/tree/main/docs/ai-coding)、[AI Agent](https://github.com/sunkailun1992/ai-agent/tree/main/docs/ai-coding)。这些项目各自的运行风险和技术栈不直接移植到本项目。
